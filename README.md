# Mundo Marino

Este es un proyecto de desarrollo web creado para la asignatura de  **Mariana Ocampo** . Consiste en un sitio web multipágina creado con HTML5 y CSS3 puro para divulgar historias del océano, promover hábitos sostenibles y acercar a las personas a iniciativas de conservación marina.

## Estructura

```text
.
├── index.html
├── productos.html
├── contacto.html
├── legal.html
├── css/
│   └── style.css
└── img/
```

## Cómo abrirlo

No necesita instalación ni servidor. Descarga o clona el proyecto y abre `index.html` en cualquier navegador moderno. También puedes usar la extensión Live Server de VS Code para previsualizarlo con recarga automática.

La carpeta `img/` está preparada para añadir fotografías e ilustraciones propias en futuras iteraciones. Las composiciones actuales de las tarjetas se construyen con CSS para que el proyecto funcione sin recursos externos adicionales.

## Aviso educativo

Este proyecto se ha creado con fines educativos y de concienciación ambiental. Los nombres, textos, cifras, precios, organizaciones y datos de contacto mostrados son material demostrativo y no representan una tienda, ONG o entidad legal real.
